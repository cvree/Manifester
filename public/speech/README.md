# Pre-generated speech

Everything in this directory except this file and the manifest is generated by
`npm run speech`, which needs the Kokoro container running:

    docker compose up -d kokoro
    npm run speech

Clips are named by a hash of the words, the voice, the speed, the language and
the version numbers in `src/lib/tts/versions.ts`, so regeneration is
incremental: an unchanged phrase keeps its file, and a changed dictionary gives
every affected clip a new name rather than editing an old one.

The empty manifest is committed on purpose. A build with no generated speech
should find an empty list rather than a 404, and the app then falls through to
live synthesis (or, with no backend, to the device's own voice).
